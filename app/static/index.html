How grounding works here

The tutor answers from passages retrieved from documents you approved. This is an evidence policy, not a guarantee: a language model cannot forget what it learned in pretraining, so you should always check quotations and readings against the sources. Each answer shows exactly which passages were supplied, and every citation is checked mechanically (the passage was supplied this turn, its document is approved and in scope, and quoted text appears in the passage). A valid citation does not prove the passage supports the claim — use Flag as unsupported and inspect the passage.

Retrieval is lexical (word matching with stemming). It does not match synonyms or paraphrases and is not semantic search. If your wording differs from the text, try other words.

Privacy and data flow

  • On your machine: originals, extracted text, the database and saved sessions live in the data/ folder. The server listens on localhost only. No telemetry, no accounts.
  • Demo mode ("Demo: scripted responses, not live tutoring.") never leaves your machine.
  • Live mode sends the selected passages and the conversation context to the model provider you configured (Anthropic), using an API key kept only in your local .env. It is opt-in per session and uses your own API balance — separate from any Claude Code or claude.ai credits.
  • Developing this app in a cloud coding session and running it on your computer are different environments; the app's data does not live in the cloud session.

NotebookLM

There is no live connection to NotebookLM. You can use the same original files in both. To move notes across, use Export Markdown on a session and paste/upload it into NotebookLM yourself. To bring notes back, import them here as secondary study notes; they stay separate from primary sources.

Not for

This is a personal learning tool. It is not for profiling people, ranking loyalty, collecting private political information, or persuasion campaigns. Exercise rubrics are app-created learning aids, not canonical standards, and feedback is qualitative.
